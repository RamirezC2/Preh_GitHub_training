# Preh_GitHub_training

This repository supports VSCode and GitHub training with a small Python
project scaffold that demonstrates an organized layout for source code,
tests, scripts, and documentation.

## Repository layout

```text
.
├── docs/
├── scripts/
├── src/
│   └── preh_github_training/
└── tests/
```

The files in these folders are intentionally simple so the team can use them
to practice common GitHub workflows such as branching, pull requests, code
reviews, and small test-driven updates.
